# 🚀 Eaglercraft Launcher

**A lightweight, cross-platform launcher for Eaglercraft.**

Eaglercraft Launcher is an open-source project designed to make launching Eaglercraft easier and more accessible across multiple operating systems and hardware architectures.

The goal is to provide a simple, lightweight and reliable launcher with multi-language support and the ability to connect a real Eaglercraft account.

---

## 💻 Supported Platforms

### Windows
- x86 (32-bit) - ✅ Available
- x64 (64-bit) - ✅ Available
- ARM - ✅ Available

### Linux
- x86 (32-bit) - 🔜 Planned
- x64 (64-bit) - 🔜 Planned
- ARM - 🔜 Planned

### macOS
- x86 (32-bit) - 🔜 Planned
- x64 (64-bit) - 🔜 Planned
- ARM - 🔜 Planned

### Android
- ARM - 🔜 Planned
- ARM64 - 🔜 Planned

## 🔐 Account Integration

Eaglercraft Launcher allows users to connect a real Eaglercraft account, providing an integrated account experience directly within the launcher.

---

## 🎯 Project Goals

- **Cross-platform compatibility:** Support Windows, Linux, macOS and Android.
- **Multiple architectures:** Provide builds for x86, x64 and ARM devices.
- **Multi-language support:** Make the launcher accessible to an international audience.
- **Account integration:** Allow users to connect their real Eaglercraft accounts.
- **Simplicity:** Make launching Eaglercraft as straightforward as possible.
- **Open source:** Keep development transparent and accessible to the community.
- **Continuous development:** Improve the launcher and expand platform support over time.

---

## 🛠️ Development

The project is currently under development, with Windows builds already available.

Support for Linux, macOS and Android is planned for future releases.
